# Atlas Tecnológico Mundial

Atlas Tecnológico Mundial es una plataforma web interactiva inspirada en herramientas de visualización de datos como FiscalMap.

Permite explorar el ecosistema tecnológico de diferentes países mediante un mapa interactivo, estadísticas, gráficos y comparativas.

El objetivo del proyecto es ofrecer una experiencia moderna con una interfaz profesional y una arquitectura limpia.
